## Sobre mí

Soy desarrollador web full-stack con proyectos completos publicados: desde el diseño de la lógica de
negocio y las APIs hasta la interfaz, las pruebas y el despliegue. Vengo del mundo de los sistemas
(ASIX), así que también me muevo con soltura en redes, servidores y soporte técnico.

Busco empleo como desarrollador web (full-stack, backend o frontend) y oportunidades en sistemas,
soporte técnico e infraestructura.

Todos tienen demo publicada, README y código abierto. Las capturas y los detalles están en cada repositorio.
