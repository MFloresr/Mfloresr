## Proyecto destacado

### Mi Jornada

Aplicación web full-stack para registrar jornadas laborales, calcular horas
trabajadas y consultar el sueldo generado por cada registro.

#### Funcionalidades principales

- Autenticación de usuarios.
- Registro de jornadas laborales.
- Cálculo automático de horas trabajadas.
- Descuento opcional de una hora de comida.
- Cálculo del sueldo por registro.
- Dashboard con estadísticas.
- Calendario interactivo.
- Sugerencias de lugares de trabajo.
- API REST desarrollada con Django REST Framework.
- Panel de administración de Django.

#### Tecnologías utilizadas

```text
Django · Django REST Framework · Vue 3 · Vite · Axios
Tailwind CSS · DaisyUI · SQLite · PythonAnywhere
```
